# US Bike Share Analysis

A course project from 2021, kept as it was written. A Python script that reads bike share trips in Chicago, New York City and
Washington (January to June 2017) and answers questions about them in the terminal.

## What it shows
You pick a city, a month (or all of them) and a day of the week (or all of them). The script then prints:
- the most common month, day of the week and start hour;
- the most used start station, end station and start-to-end trip;
- the total and the average trip duration;
- the counts of user types, and for Chicago and New York City (the two files that have them) gender and birth year.

## Run it
Python 3 with pandas and NumPy, the three CSV files in the same folder:

```
python Project1.py
```
